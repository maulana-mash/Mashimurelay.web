Petunjuk Penggunaan Mashimurelay

Panduan lengkap CAD, ensiklopedia komponen & simulasi otomasi industri
Video Simulasi Interaktif: Saksikan pergerakan fisis kontak, aliran arus, dan medan magnet secara real-time:

1. Definisi Software

Mashimurelay adalah perangkat lunak Computer-Aided Design (CAD) dan simulator interaktif teknik kelistrikan industri yang dirancang khusus untuk merancang, menguji, dan menganalisis sistem kendali elektromagnetik, otomasi industri berbasis relai (hardwired relay logic), serta rangkaian tenaga motor listrik.

Mengadopsi standar internasional diagram kelistrikan (IEC 60617 dan NEMA ICS 19-2002), menghadirkan lingkungan virtual real-time di mana setiap komponen kelistrikan dimodelkan secara fisis dan logis sesuai karakteristik aslinya di dunia industri nyata.

2. Kegunaan & Manfaat Utama

  • Perancangan Diagram Kontrol & Tenaga: Menggambar sirkuit kendali dan sirkuit daya pada snap-grid 30px presisi tinggi.
  • Simulasi Logika Relai Real-Time: Memvalidasi fungsi interlocking, penguncian mandiri, urutan sekuensial motor, Forward-Reverse, Star-Delta, hingga otomasi flasher.
  • Analisis & Proteksi Hubung Singkat: Mendeteksi korsleting seketika sebelum diaplikasikan pada panel listrik nyata.
  • Portabilitas & Kompatibilitas Penuh: Bekerja offline (PWA) di Windows dan Android dengan format berkas .smrl dan .txt.

3. Tujuan Pengembangan

  1. Keamanan Tanpa Risiko: Menghilangkan risiko peralatan meledak, terbakar, atau hubung singkat saat proses belajar dan prototyping.
  2. Efisiensi Waktu & Biaya: Menguji logika sistem kontrol secara instan tanpa perlu merakit kabel secara manual pada papan uji.
  3. Standarisasi Pendidikan Vokasi: Menjadi sarana ajar interaktif untuk teknik elektro, mekatronika, dan instalasi tenaga listrik industri.

1. Navigasi Antarmuka & Kanvas

  • Buka Menu: Klik logo MASHIMURELAY di pojok kiri atas untuk membuka panel navigasi drawer.
  • Pencarian & Penempatan Komponen: Cari komponen di sidebar kiri, klik untuk menempatkan di kanvas. Geser menggunakan mouse (snap 30px otomatis).
  • Rotasi Komponen: Klik komponen lalu tekan tombol keyboard R atau klik tombol Putar pada kapsul melayang.
  • Pemberian Tag Interlocking: Klik komponen (misal kontak bantu), ketik Tag yang sama dengan koil pengendali (misal: -KM1).

2. Penarikan Kabel (Wiring System)

  • Arahkan kursor ke terminal pin komponen (lingkaran cyan).
  • Klik sekali pada pin asal, lalu klik pin target pada komponen lain. Kabel ortogonal rapi akan otomatis terbentuk.
  • Proteksi Sambungan Mandiri: Kabel dilarang menghubungkan pin komponen ke pin lain pada komponen yang sama.

3. Menjalankan Simulasi

  • Tekan tombol hijau ▶ Run (atau shortcut P). Mode simulasi aktif ditandai dengan badge hijau RUNNING.
  • Klik Push Button atau putar Saklar di kanvas untuk mengamati arus listrik mengalir, koil menyala, timer menghitung mundur, dan motor berputar.
  • Kabel aktif akan menyala terang (fasa berwarna merah/biru cerah, netral cyan).
  • Jika terjadi hubung singkat (korsleting), sistem proteksi instan akan memutus daya dan memunculkan banner peringatan SHORT CIRCUIT!.
  • Tekan tombol merah ⏹ Stop untuk mengakhiri simulasi dan kembali ke mode pengeditan skema.

4. Manajemen File & Penyimpanan

  • Auto-Save: Dapat diatur aktif atau nonaktif melalui menu Settings.
  • Format .smrl: Berkas standar CAD modern berbasis JSON lengkap dengan metadata posisi.
  • Format .txt: Format native Simurelay Android agar dapat dibuka langsung di aplikasi handphone.

Penutup & Komitmen Pembelajaran

Mashimurelay dirancang sebagai platform terpadu untuk menjembatani teori otomasi kelistrikan dengan implementasi industri nyata. Melalui simulasi berpresisi tinggi ini, perancang dapat memvalidasi desain sistem kendali tanpa risiko kesalahan perangkat keras.

Peringatan Keselamatan Instalasi Fisik Nyata:
Selalu patuhi standar K3 Listrik dan prosedur Lockout/Tagout (LOTO). Pastikan sumber tegangan telah dimatikan total dan ukur dengan voltmeter sebelum menyentuh kabel pada panel industri fisik. Hasil simulasi virtual ini adalah panduan konseptual dan verifikasi logika.
